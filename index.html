Beyond Point-Attached Semantics:
Stable Object-Centric Semantic Fields for Robust Manipulation

Experiment Videos Method Results

Grasping a mug by its handle and placing it on the target base.

Abstract

Robotic manipulation often requires identifying functional parts, such as a mug handle or a hammer head. However, features attached to observed 3D points can vary with viewpoint and sensor noise, giving a policy inconsistent representations of the same part. We propose an object-centric semantic field to provide more consistent part-aware features for manipulation. We use the observed object cloud to build a continuous field, then read features from this field at 3D locations independently resampled from the cloud. Each feature is inferred from the whole object observation rather than taken directly from an individual input point. Part supervision teaches the field to distinguish functional regions and align corresponding parts across object instances, while training with perturbed observations encourages consistent predictions. The queried coordinates and features form semantic point clouds that are supplied to a DP3-based policy. We evaluate the approach on four RoboTwin simulation tasks and four real-world bimanual tasks, achieving average success rates of 69.3% and 67.5%, respectively. These exceed the strongest evaluated baseline in each setting by 7.0 and 32.5 percentage points, with real-world evaluation performed on held-out objects. These results highlight the value of stable, object-conditioned semantic fields for manipulation across object instances and varying observations.

Method Overview

Construct the Field

A frozen Utonia encoder provides geometric features. A learned adapter, three feature grids, and a global feature supply object context for query decoding.

Learn Part Semantics

PartNext labels supervise one field per category. Part classification, cross-instance alignment, and perturbation consistency encourage distinct yet consistent part features.

Train the Policy

The field is frozen. Separate PointNets encode the scene and semantic object clouds; their features and encoded robot state condition a DP3 action-denoising network.
